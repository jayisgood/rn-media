ReadyNote Shorts Uploader - Privacy Policy

Last updated: October 10, 2026

ReadyNote Shorts Uploader is a private tool used only by ReadyNote, a small digital planner and template shop, to upload and schedule short videos to ReadyNote's own YouTube channel. It is not offered to the public and no other user can sign in to it.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • The channel ID and title of the authorized ReadyNote channel, to confirm it is uploading to the right channel.
  • The list of recent uploads on that channel, to avoid uploading the same video twice.
  • Public statistics (views, likes, comments) of videos the tool uploaded, to measure which videos work.

The tool uploads videos, titles and descriptions that ReadyNote created itself. It does not access any other user's data, comments, subscribers or private information.

How data is stored and shared

The OAuth refresh token and the upload records (video ID, title, upload time, statistics) are stored only on ReadyNote's own computer. Nothing is sold, shared with third parties, or used for advertising.

Deleting data and revoking access

Stored records are kept while the tool is in use and are deleted when it is retired. Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the stored token stops working and is deleted.
